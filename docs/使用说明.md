# Darius Music 使用说明

一个 Windows 音乐播放器：本地曲库 + 桌面歌词。绿色版，不需要安装。

## 第一次用

1. 双击 `Darius Music.exe`。
2. 左侧「本地音乐」→「添加音频文件…」，或把音乐文件夹拖进来；也可以点「在线搜索」直接找网易云上的歌。
3. 点任意一行开播（再点正在播的那行就暂停）。右下角「桌面歌词」滑块控制桌面上的那层歌词。

## 曲库

- 支持 `mp3 / flac / m4a / aac / wav / ogg / wma`，会读标签与内嵌封面（没有封面时用文件名）。
- 同名 `.lrc` 自动加载；支持行时间 `[mm:ss.xx]`、逐字 `<mm:ss.xx>`、双语歌词。
- **单击**一行播放，再点正在播的那行暂停；行可以拖动排序。
- 歌单：左侧「＋ 新建」；右键歌单可以「添加歌曲… / 重命名 / 更换封面 / 清理失效条目 / 删除歌单」。
- 单曲：右键「添加到歌单… / 另存到… / 从当前列表移除」，删除后 6 秒内可以撤销（不会删文件）。

## 在线

- 「在线搜索」输入歌名或歌手，回车。双击直接播（边下边播），右键可以下载到本地。
- 想要更高音质或 VIP 曲目：设置 →「下载与存储」里粘贴自己的网易云 Cookie（浏览器登录 music.163.com 后，从开发者工具任意请求里复制整段 Cookie，要含 `MUSIC_U`）。留空即匿名。
- 支持落雪（LX）音源脚本，放在数据目录 `lx\` 下即可被识别。

## 桌面歌词

- 开关：主界面右下角「桌面歌词」。
- 拖动：直接在歌词上按住拖，位置会记住；右键有「锁定穿透 / 重置位置 / 设置」。
- 设置里可调：字号、行宽、行距、显示行数、当前行放大、不透明度、文字颜色、歌词辉光（强度 / 范围 / 颜色）、3D 倾斜角度与交点位置、背景（跟随封面 / 自定义图片 / 纯色 / 透明）与边缘羽化、垂直位置。
- 设置里所有滑块都**只能拖动**：点一下轨道不会把参数挪一格。
- 歌词偏移：全局偏移调所有歌；「本歌曲偏移」只影响当前这首，每首单独记住。

## 播放页

点播放条左侧的封面/空白处进入全屏播放页（窗口窄时是竖屏排版）。右上角「⋯」里是这一页自己的字号、行数、辉光、倾斜、背景参数，和桌面歌词互不影响。

## 外观

设置 →「界面外观」：主色、背景色（整窗配色由这两个推导，浅色主题会自动换成深字）、背景图（可以选「当前歌曲封面」）、不透明度、磨砂。

## 更新

「检查更新」会读更新清单，有新版本就下载到 `versions\` 新目录并切换指针，**不会覆盖正在运行的文件**。更新源可以在设置里填，也可以放在程序目录的 `update-feed.txt` 里（一行地址，`#` 开头是注释）。

## 数据

所有数据都在程序目录的 `data\`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 设置、曲库、每首歌的歌词偏移、Cookie |
| `playlists.json` | 歌单 |
| `covers\` `lyrics\` `stream\` `downloads\` | 封面、歌词、流式缓存、下载中转 |

删掉 `data\` 就恢复默认（歌单和设置都会没，音乐文件不受影响）。

## 快捷键

| 场景 | 操作 |
|---|---|
| 桌面歌词 | 滚轮：调字号（±3）；右键：菜单（设置 / 鼠标穿透 / 重置位置 / 显示翻译 / 背景柔光 / 置顶 / 上一首 / 播放暂停 / 下一首 / 关闭） |
| 主界面 | 单击行：播放；再点当前行：暂停；Esc：关闭播放页 |
| 拖动排版 | 歌曲行可以按住上下拖动重新排序 |
